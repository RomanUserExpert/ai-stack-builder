The product's look as one package. Every screen links one file, and so does this page: the components below are not pictures of the product, they are the product's own markup on the product's own stylesheet. Switch the theme at the top right and every one of them changes, because a theme overrides roles and nothing else.

#!/usr/bin/env bash
# Fix what ESLint can fix, on staged files only.
files=$(git diff --cached --name-only --diff-filter=ACM | grep -E '\.(ts|tsx)$')
[ -z "$files" ] && exit 0
npx eslint --fix $files && git add $files
