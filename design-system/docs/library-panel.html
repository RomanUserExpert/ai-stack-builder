When to use

The configuring mode's only corpus surface. It answers what goes into this project; it reads and adds, and never edits (Q14). A zero result keeps the row that creates, which summons the Item sheet over the project.

Rule and anti-rule

Use it

Only in the configuring mode. It opens on Related, or on All when the project is empty (Q33).

Take another

Keeping, editing and deleting items happen in My library and its Item sheet. A panel that could edit would be a second library. → Item sheet
