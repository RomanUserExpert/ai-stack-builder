[ -z "$files" ] && exit 0
npx eslint --fix $files && git add $files

When to use

An item opened from a set row, beside the set rather than over it. It is the only place Detach, Reset and Promote live (Q33), and on a detached item it names the fields that differ from the original.

Rule and anti-rule

Use it

One item at a time; its row carries the lime pill while it is open. Promote is immediate, because it creates a library item.

Take another

Editing the library original is the Item sheet, over My library: the side panel only edits a detached copy, and only in the configuring mode (Q21). → Item sheet
