My everyday setup across machines: commit conventions, the review subagent, the filesystem and memory MCP servers.

  1. commit-conventionsprompt

    Conventional commits, imperative mood, and a body that says why rather than what.

    Maya’s own

  2. pr-revieweragent

    Reads a pull request diff and leaves review comments the way I would write them.

    Requires github-mcp

    Maya’s own

  3. code-styleskill

    How I want TypeScript written: naming, imports, error handling, no default exports.

    Defers to the client’s ESLint config — where they disagree, that wins

    Maya’s own

  4. github-mcpmcp

    Issues, pull requests and code search on GitHub, through GitHub’s own server.

    Needs GITHUB_TOKEN · auto-added for pr-reviewer

    github/github-mcp-server @ v0.9.0 · MIT

  5. filesystemmcp

    Read and write files inside the directories you allow, and nowhere else.

    modelcontextprotocol/servers @ 2025.9.25 · MIT

  6. memorymcp

    A knowledge graph the agent can write to and read back between sessions.

    modelcontextprotocol/servers @ 2025.9.25 · MIT

  7. session-notesskill

    Keeps a running log of decisions in NOTES.md at the end of each session.

    Requires memory

    Maya’s own

  8. shell-safetyprompt

    Never run destructive commands without saying what they delete first.

    Maya’s own

  9. dotfiles-syncscript

    Links the agent config into ~/.claude on a new machine.

    Maya’s own
